# V5.21.6 — active graph qualification and activation readiness

Use the existing pinned draft.4 qualification on private exact copies of selected active profile inputs. The read-only preflight checks native source hashes, state index, candidate inventory, the original bound editorial packet and registration plan, absence of existing profile and target collisions, and pending registration journals. This is not an approval or a write transaction. Historical registered entries' bytes are not independently revalidated. No production activation command exists. Before any future activation: authenticate independent editorial decision bound to the packet, plan and reader qualification; enforce domain policies; lock workspace; stage all role/layer bytes; write durable multi-artifact journal; register and verify roles; publish profile last; rebuild private index; implement and test recovery at each interruption. The existing per-artifact registration journal is insufficient alone for full-profile atomicity. This overlay only produces the required phases and readiness evidence. Structured and specialized packets are revalidated, not promoted to V11.
